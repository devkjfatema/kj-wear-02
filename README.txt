KJ Wear — চালানোর নিয়ম

ক) শুধু ফ্রন্টএন্ড (সার্ভার ছাড়া, ডেমো)
   index.html ডাবল ক্লিক করুন। অর্ডার শুধু ব্রাউজারে সেভ হয়, WhatsApp বাটনে পাঠানো যায়।

খ) পূর্ণ সাইট (অর্ডার, অ্যাডমিন প্যানেল, পেমেন্ট সহ)
   লাগবে: Node.js 18+ এবং চালু MySQL/MariaDB।
   1. টার্মিনালে:  cd server  →  npm install  →  npm start
   2. প্রথমবার চালালে server/.env আপনা-আপনি তৈরি হয় এবং টার্মিনালে অ্যাডমিন পাসওয়ার্ড দেখায়।
      MySQL এর পাসওয়ার্ড থাকলে server/.env এ DB_PASSWORD বসান, তারপর আবার npm start।
      ডেটাবেস ও টেবিল আপনা-আপনি তৈরি হয়, ২৪টা প্লেসহোল্ডার পণ্য সিড হয়।
   3. সাইট:  http://localhost:3000   |   অ্যাডমিন:  http://localhost:3000/admin/
   4. অ্যাডমিন থেকে: পণ্য যোগ/সম্পাদনা, ছবি আপলোড, অর্ডার দেখা, স্ট্যাটাস বদলানো,
      bKash/Nagad এর TrxID মিলিয়ে "পেমেন্ট মিলেছে" চাপা।

সেটিংস
   js/config.js  — নাম, WhatsApp, bKash/Nagad নম্বর, ডেলিভারি চার্জ, কুপন, হিরো ছবি, ভাষা
                   (সার্ভার এই ফাইল থেকেই চার্জ ও কুপন পড়ে, তাই দুই জায়গায় বদলাতে হয় না)
   js/products.js — শুধু সার্ভার ছাড়া ডেমোর পণ্য। সার্ভার চালু থাকলে পণ্য ডেটাবেস থেকে আসে।
   server/.env   — ডেটাবেস, অ্যাডমিন পাসওয়ার্ড, BASE_URL, bKash ও SSLCommerz key

অনলাইন পেমেন্ট চালু করতে (ঐচ্ছিক)
   bKash:       server/.env এ BKASH_* চারটা মান দিন (sandbox এ আগে পরীক্ষা করুন)
   কার্ড:       SSLCZ_STORE_ID ও SSLCZ_STORE_PASS দিন
   BASE_URL:    সাইটের আসল https ঠিকানা দিন, নইলে পেমেন্ট ফেরত আসবে না
   Nagad API ও Stripe এখনো যুক্ত হয়নি। Nagad ম্যানুয়াল মোডে (নম্বর + TrxID) চলে।
